### 防护是两档，不是一档

官网首页写着 “up to 600 Gbps mitigation capacity”，读起来像标配。官方文档写得很清楚：默认档是 best-effort 基础清洗，600Gbps 专业清洗是付费加购项，文档里没有给出价格，只写了联系支持。

官方列出的防护覆盖 L3/L4 的 UDP Flood、SYN Flood、ACK Flood、ICMP Flood、DNS 与 NTP 放大攻击，以及 L7 的 HTTP Flood、CC、Slowloris，并注明 L7 策略会随节点和防护档位变化。

这里有一条只写在文档里、但对决策影响极大的规则：当实例遭受大规模攻击并影响到同网段其他客户时，系统会对该 IP 自动黑洞，持续 30 到 60 分钟，自动解除，**无法人工干预**。黑洞期间所有进出流量全部丢弃，业务就是断的。

换句话说，GoMami 的基础防护能处理一部分攻击，但处理不了“大到惊动邻居”的那种。如果你的业务一小时停机就是事故，这条规则足以把你推向物理高防；如果只是博客、测试环境、内部工具，黑洞半小时基本无所谓。

延迟也顺便纠一个常见误读：官网首页笼统写 RTT <50ms，文档的 Locations 表和 Network FAQ 两处都写新加坡节点到中国大陆 <70ms（中国香港 <30ms、日本 <50ms）。新加坡的物理距离摆在那里，70ms 才是可信口径，官方也建议先 ping 测试再买。

## 差价到底差在哪：防御带宽的定价远高于算力

拿两组数字放一起看最清楚。GoMami SIN.Pulse.Ultra 是 12 核 32G、300GB NVMe、10TB 流量、$338/月；华纳云 100G 防御档是 16G 内存、20Mbps 带宽、¥5000/月，折合接近 $700，计算资源配置还不如前者。

多出来的钱买的是清洗能力。原理不复杂：加密流量要解密才能识别，SSL/TLS 握手会实打实吃 CPU；普通网卡在持续大流量冲击下的丢包也会先于带宽跑满。所以高防套餐普遍配老 CPU、小带宽、大清洗池——算力被清洗和转发吃掉了，业务本身跑不快，但抗打。厂商在宣传里给出的具体倍数（多少核能扛多少次解密、多大网卡能把功耗降几成）属于各自测试环境下的口径，不同攻击类型差别很大，当参考就好，别当普适结论。

反过来，GoMami 把预算全砸在 EPYC 和 NVMe 上，性能确实到位——第三方测评里 SIN.Pulse 系列的磁盘和单核成绩在同价位里属于上游水平——但防护就只能停在 best-effort。

## 常见问题

**GoMami 新加坡算不算高防服务器？**
严格说不算标配高防。它默认提供 best-effort 基础清洗，600Gbps 专业清洗是付费加购项。把它放进“新加坡高防服务器”名单里，理由是这个加购选项存在，而不是它自带 T 级防御。

**新加坡节点到中国大陆延迟多少？**
官方文档口径是 <70ms，中国香港 <30ms、日本 <50ms。实际延迟随本地 ISP 和网络状况变化，官方建议购买前先测试。

**被 DDoS 打了会怎样？**
基础清洗会自动介入，无需配置。如果攻击规模大到影响同网段其他客户，IP 会被自动黑洞 30–60 分钟，自动解除，期间无法人工干预，也无法提前解封。

**流量跑完了会停机吗？**
不会。可以按 $6/100GB 自助加购，当月生效。长期不够用就升套餐。

**支持 Windows 吗？**
SIN.Pulse.Pro 和 Ultra 标注了 Windows-ready，前三个套餐没有标注。Windows 授权是否额外收费，资料里没有说明，下单前问一下客服比较稳。

**新加坡有 GoMami 的独立服务器吗？**
没有。Forge 独服系列只在中国香港，新加坡只有 Pulse 这一条 VPS 线。
